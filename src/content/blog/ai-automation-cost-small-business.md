short_answer: "Cost depends on how many processes, systems and people an automation touches. A single workflow between two tools is a small project. A system that spans several teams and needs custom software is a larger one. A scoped audit gives you a fixed quote before any build starts."
sections:
  - heading: "What drives the cost"
    body: "Three things set the price: the number of steps in the process, the number of systems it connects, and how much judgment the AI has to apply. Clean data and modern tools with APIs keep costs down. Spreadsheets, PDFs and older software push them up."
  - heading: "Build cost vs. running cost"
    body: "A project has a one-time build cost and an ongoing cost to run it: software subscriptions, AI model usage and maintenance. Ask for both numbers up front. A managed retainer rolls the running cost into one monthly fee."
  - heading: "How to estimate payback"
    body: "Count the hours the process takes each week, multiply by what those hours cost, and compare that with the build and running cost. Start with the process that pays back fastest."
  - heading: "How to get a fixed quote"
    body: "Write down the process as it runs today, who touches it and which tools are involved. A free audit turns that into a written scope and a fixed price."
faqs:
  - question: "Is AI automation worth it for a small team?"
    answer: "Usually, when a process repeats every week and follows clear rules. Start with one process and measure the hours saved."
  - question: "Do I need to replace my current software?"
    answer: "No. Most automations connect the tools you already use."
